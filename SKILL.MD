# Skill Name: Confluence Game Design Document (GDD) Writer

## Purpose
This skill configures the AI agent to write comprehensive, production-ready Game Design Documents directly optimized for Confluence markdown. It strictly enforces the exact structural taxonomy, programmatic language, documentation layouts, and feature breakdown mechanics found in the project's historical documentation templates (e.g., Collections 2 and Collections 3).

---

## 1. Core Structural Taxonomy & Hierarchy
Every document generated by this skill must rigidly follow this explicit top-down layout:

1. **Title Header:** Format exactly as `GDD - [Feature Name] - [Sub-Feature or Variant Name]` (e.g., `GDD - Collections 2 - Caps & Crew Capsules`).
2. **Table of Contents / Index:** A clean numerical hierarchy list mapping out every major and sub-section.
3. **Summary Section:** A concise 1-2 paragraph pitch explaining the target player feature, its basic functional loops, and design additions.
4. **Figma & Jira Links Block:** Embedded list of exact reference names for downstream asset maps (e.g., `SD-232 [RM_2026] Character collection`, `SURF-40168: Collections | Phase 1`).
5. **One-Pager Matrix (Strict Table Format):** A 4-column alignment table containing:
   | Problem Statement | User Story | Acceptance Criteria | Expected Outcomes |
   | :--- | :--- | :--- | :--- |
6. **MVP / Release Overview:** Clear bulleted separation dividing features into explicit technical scopes (e.g., `MVP`, `Not MVP`, `Collections 3.1`, `Collections 3.2`).
7. **Numbered Technical Explanations:** Deep structural dives using decimal sub-sectioning (`1.`, `1.1`, `1.2`, `2.`, `2.1`).
8. **Shared Appendices:** Mandatory ending elements detailing structural dependencies: `Art Requirements`, `SFX (To Do)`, `Profile Data (To Do)`, `Localization (To Do)`, `Analytics (To Do)`.

---

## 2. Formatting & Visual Layout Syntax
To integrate cleanly with Confluence layouts, the agent must output specific markdown block decorations:

* **Confluence Callout Blocks / Expanders:** Use markdown syntax blocks or explicitly labeled callout text headers like `Expand to see a table view` or `UX Notes`.
* **Asset Trackers:** Any incomplete asset configuration must be flagged with a standard uppercase tracker notation: `TO DO: Final assets needed.` or `[Image/Video Placeholder]`.
